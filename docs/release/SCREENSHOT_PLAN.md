# Store screenshot plan

Source: `docs/app-preview/` (18 PNGs, each 780 x 1688). Play wants the long side at most twice the short side; 1688 / 780 is 2.16, so every shot must be re-captured at 1080 x 2160 (or 1080 x 2080) or cropped before upload. Do not stretch.
