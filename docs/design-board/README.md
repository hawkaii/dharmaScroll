# DharmaScroll design board

1. Open `docs/design-board/index.html` in any browser (double-click; no server, no network).
2. Drag to pan. Ctrl/Cmd + wheel (or the +/- buttons) to zoom. Top bar jumps to a section.
3. Light/dark phones sit side by side. Click buttons to feel the press. Motion demos loop on their own.
4. `tokens.json` holds every colour, type, spacing, radius and motion value (the source for the Flutter theme).
5. Fonts load from `../../assets/fonts/` (Archivo, Tiro Devanagari). Lottie art is shown as SVG stand-ins.
